# DOT NET Job Portal

Job portal and recruitment platform built with ASP.NET for employers and job seekers.

## 🚀 Features

- 📋 **Job listings** - Browse and post job opportunities
- 👤 **User profiles** - Resume builder and profile management
- 🔍 **Advanced search** - Filter by location, skills, experience
- 📝 **Application management** - Track applications and status
- 🏢 **Company profiles** - Company pages and reviews

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: ASP.NET
- **Database**: SQL Server
- **Framework**: .NET
